# yt-dlp Playlist Downloader & Post-Processor

Automated YouTube audio downloader and tag post-processing workflow designed for DJ libraries (such as Pioneer Rekordbox).

Downloads playlists, embeds cover art & metadata, cleans up YouTube Music artifacts, identifies genres via iTunes API, crops album artwork to 1:1 square, and auto-moves finished tracks to a designated library folder for instant ingestion.

---

## Features

- **High-Quality Audio Extraction**: Downloads YouTube playlists as MP3 (320kbps / best audio quality) using `yt-dlp`.
- **Genre Tag Auto-Detection (`update_genres.js`)**: Queries the iTunes / Apple Music search API by title and artist to populate accurate ID3 genre tags.
- **Square Artwork Cropping (`crop_covers.js`)**: Auto-crops borders and centers cover thumbnails to a clean 1:1 square ratio for DJ software display.
- **YouTube Topic Cleaner (`remove_topic.js`)**: Removes `" - Topic"` suffixes from artist ID3 tags and filenames generated by YouTube Music automated uploads.
- **Rekordbox Auto-Move & Overwrite Prompting**: Moves finished tracks to your DJ library (default: `G:\My Drive\01 - DJ Files\Tracks`) with overwrite prompts for existing files.

## Setup on a New Machine

### 1. Prerequisites
- **PowerShell** (5.1+ or PowerShell 7)
- **Node.js** (v18 or newer): [nodejs.org](https://nodejs.org/)
- **yt-dlp.exe**: Download the Windows executable from [yt-dlp releases](https://github.com/yt-dlp/yt-dlp/releases) and place it in this folder (or add to your system `PATH`).
- **ffmpeg** (Optional but recommended): Ensure `ffmpeg` is available on your system `PATH` for optimal audio conversion.

### 2. Install Node Dependencies
In the repository folder, install the required npm packages:
```powershell
npm install
```

## Usage

### Run interactively
```powershell
.\download_playlist.ps1
```
The script will prompt for:
1. The YouTube Playlist URL.
2. Confirmation to move processed tracks to the DJ folder (defaults to `G:\My Drive\01 - DJ Files\Tracks`).
3. Overwrite decisions if any files already exist (`[Y]es / [N]o / [A]ll / [S]kip all`).

### Run with Parameters
```powershell
# Specify URL directly and auto-move without asking:
.\download_playlist.ps1 -PlaylistUrl "https://www.youtube.com/playlist?list=..." -AutoMove

# Specify a custom destination folder:
.\download_playlist.ps1 -PlaylistUrl "..." -DestinationDir "D:\DJ\New Tracks" -AutoMove

# Keep downloaded files in the current folder without moving:
.\download_playlist.ps1 -PlaylistUrl "..." -NoMove
```

## Rekordbox Auto-Import Integration

To have tracks automatically added to your Rekordbox collection:
1. Open **rekordbox**.
2. Go to **Preferences** (`Ctrl + ,`) > **Advanced** > **Library** tab.
3. Under **Auto Import**, enable the checkbox and set the folder to your destination path (e.g. `G:\My Drive\01 - DJ Files\Tracks`).
4. Whenever tracks are moved to that folder, rekordbox will automatically ingest and analyze them.
